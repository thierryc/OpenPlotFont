What & why

A font for
drawing letters.

A regular font describes the outline of a letter. A stroke font describes the path your pen follows.

PlotFont stores those paths, together with spacing, Unicode mappings, and drawing order, in a readable .plotfont.json file. Separate strokes keep their pen lifts. Loops remain loops. Curves remain curves.

A glyph can also include explicitly filled shapes and holes. Your drawing software sets the physical size and prepares fills for the actual tool. That keeps the font useful across different pens and machines.

How it works

Draw. Export. Use.

One editable source, one portable font.
Your plotter application handles the machine.

  1. 01

    Edit in Glyphs

    Open a catalog font or draw your own centerlines. Use a separate path wherever the pen should lift.

    .glyphs / .glyphspackage
  2. 02

    Export PlotFont

    Choose a master and export its paths, metrics, and spacing with the Glyphs plugin.

    .plotfont.json
  3. 03

    Prepare the drawing

    Lay out text and choose a size in your drawing software. The reference tools can render a specimen to SVG.

    SVG → your drawing workflow

PlotFont is a draft font format and authoring toolkit. Machine output and device control belong to consumer applications. The exporter reads authored paths; automatic outline-to-centerline conversion is not included.

Coverage and preparation notes

All 87 packages were saved and reopened in Glyphs 4.1.1, then compared with their source conversions. These are font preparations; physical plotting has not been tested. Fourteen non-Latin and symbol JHF sources use temporary private-use mappings, identified on their cards. Script sources preserve pen lifts; automatic joining and substitutions are not supplied by this catalog. SVG arcs are converted to curves with a documented tolerance.

EMS fonts are existing stroke derivatives. Regular Google Fonts outlines are not automatically converted into centerlines. Conversion details and upstream credits are retained in each ZIP.

The self-contained plugin exports one master as geometry-only PlotFont 0.3. Install it once; no repository checkout is needed afterwards.

Download the Glyphs plugin ↓

For Glyphs 4 on macOS. Open the ZIP to get PlotFont.glyphsFileFormat.

Plugin documentation ↗

  1. Install

    Drag PlotFont.glyphsFileFormat onto Glyphs 4 and accept the installation prompt.

  2. Restart Glyphs

    Save your work, then quit and reopen Glyphs to load the plugin.

  3. Export a font

    Open your source. Choose File → Export → PlotFont, select one master, and save to a new .plotfont.json filename. Existing files are preserved.

Preview status: native export actions and installation were verified in Glyphs 4.1.1. Startup and the visible export tab still need qualification after restart. See the current compatibility notes and the Glyphs installation guide.

Build from source or use the export script

Build the plugin

Download or clone the repository. From its folder, run this with Python 3.10 or later:

python3 scripts/build_glyphs_plugin.py

Install the complete bundle from output/build/PlotFont.glyphsFileFormat.

Install the workspace script

Keep the repository intact. In Glyphs, use Script → Open Scripts Folder, then create a symlink there to scripts/Export PlotFont.py in your checkout. Refresh the menu with Option held while opening Script, then choose Reload Scripts.

Configure the font ID and a new absolute destination as described in the script setup guide. The script imports the repository’s Python package, so copying the script alone will not work.

Its default geometry export is legacy 0.2; the explicit matching compiled-font workflow adds optional 0.3 OpenType layout.
